This is a sample post. Add new posts by creating another .mdx file in src/content/blog/. The file name becomes the URL, so my-post.mdx is served at /blog/my-post/.

What you can use

Every post starts with a metadata export containing title, date (YYYY-MM-DD) and summary. After that, write regular Markdown:

  • Bold, italic and inline code
  • Links
  • Tables, task lists and strikethrough (GitHub-flavored Markdown)
